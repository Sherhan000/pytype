# pytype: всё, что нужно знать, чтобы продолжить работу

Этот файл для нового чата с Claude. Прочитай его целиком, прежде чем что-то менять.

## Что это

pytype это тренажёр скоростной печати кода на Python с играми и соревнованиями. Владелец SherJahon (ник на сайте Sherjahon, он админ).

- Сайт: https://pytype.onrender.com
- Код: https://github.com/Sherhan000/pytype (публичный репозиторий, ветка main)
- Копия на компьютере владельца: `C:\Users\user\Downloads\pytype`
- Хостинг: Render, бесплатный тариф, сервис `srv-db5rhs0473hc73c5pj00`
- База: Neon Postgres, бесплатный тариф, регион Frankfurt
- ИИ: Groq API, основная модель llama-3.3-70b-versatile

## Как общаться с владельцем

- Пиши простым разговорным русским, без канцелярита.
- Никогда не используй длинное тире в русском тексте.
- Тексты на сайте не должны звучать как написанные ИИ.
- Код без комментариев и докстрингов, короткие имена переменных, естественный стиль, без лишних абстракций.
- Владелец не программист в деталях, объясняй шаги коротко и по-человечески.

## Стек

Node.js 20+, ESM. Express 5, Socket.io 4, helmet с CSP, compression, bcryptjs, jsonwebtoken (кука `tk` на 30 дней), pg для Neon. Если `DATABASE_URL` нет, используется встроенная база PGlite в папке `data/` (так удобно проверять локально). Фронтенд на чистом JS без сборки, SPA на хеш-роутах.

## Переменные на Render (Environment)

`DATABASE_URL`, `GROQ_API_KEY`, `ADMIN` (ник админа), `JWT_SECRET`, `NODE_ENV=production`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`. Ещё не заданы: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`. Необязательные: `PUBLIC_URL`, `APP_TZ` (по умолчанию Asia/Tashkent), `VAPID_*`.

Секреты и ключи вставляет только владелец. Claude их в поля не вводит.

GitHub OAuth App: «pytype», id 3928499 в настройках GitHub, callback `https://pytype.onrender.com/auth/github/cb`. Владелец собирался после теста перевыпустить секрет.

## Как выкладывать изменения

Прямого доступа на запись к репозиторию у Claude нет (GitHub App Claude не установлен). Рабочий способ:

1. Правишь код у себя и проверяешь (см. ниже).
2. Через доступ к компьютеру владельца кладёшь файлы в `C:\Users\user\Downloads\pytype` с той же структурой папок. Папку `.github` через этот инструмент записать нельзя. Большие пачки иногда отваливаются по таймауту, тогда досылай частями.
3. Во встроенном браузере открываешь `https://github.com/Sherhan000/pytype/upload/main`. Владелец заходит внутрь папки `Downloads\pytype`, нажимает Ctrl+A и перетаскивает всё на страницу. Перетаскивать нужно содержимое, а не саму папку, иначе файлы сваливаются в одну кучу. Проверь в тексте страницы, что пути вида `/server/...` и `/public/js/...` на месте, и нажми Commit changes.
4. Если поменялся один файл, можно без владельца: открыть `https://github.com/Sherhan000/pytype/edit/main/<путь>`, взять редактор через `(document.querySelector('.cm-content').cmView || document.querySelector('.cm-content').cmTile).view`, сделать `view.dispatch({ changes: [...] })` точечной заменой, проверить длину и нажать Commit changes. Перед заменой проверяй, что исходная строка встречается ровно один раз.
5. Render сам не деплоит. Открой `https://dashboard.render.com/web/srv-db5rhs0473hc73c5pj00/deploys`, Manual Deploy, Deploy latest commit. Дождись в логах «Your service is live».
6. Проверь живой сайт. Если поменялись файлы фронтенда, подними версию `V` в `public/sw.js` и добавь новые js в список SHELL.

## Как проверять у себя

```
npm install
PORT=3111 node server/index.js
```

Без `DATABASE_URL` поднимется встроенная база. Удобно гонять Playwright (Chromium уже установлен): регистрируешь двух пользователей, проходишь страницы на компьютере (1360x860) и телефоне (390x844) на всех языках, ловишь pageerror и ошибки в консоли, проверяешь, что нет горизонтальной прокрутки. Непереведённые строки видно через `[...I18N.miss]` при `pt_lang=en`.

## Подводные камни

- В JS нельзя называть локальные переменные `t`: это функция перевода. Такие ошибки уже были.
- Новые строки интерфейса добавляй в `i18n-dict.js` на трёх языках. Текст внутри `code`, `.qcode`, `.exl` и редактора не переводится.
- Классы `.hl`, `.wk`, `.tag.g` уже заняты, проверяй CSS на конфликты перед новыми именами.
- Широкие страницы помечаются `wide: true` в `App.page`, роутер сам ставит класс `wide` на `#view`.
- Элемент `#view` живёт между страницами. Не вешай на него `v.onclick` и обработчики без снятия, иначе они сработают на других страницах.
- В SQL алиасы `day` и `week` ломают запрос, бери другие имена.
- Всё про дни, недели и время в базе считается по Ташкенту. Не используй `getUTCHours` и подобное.
- Бесплатный Render засыпает через 15 минут без заходов. В репозитории есть `.github/workflows/keepalive.yml`, он пингует `/healthz`. Базу Neon постоянно не держим живой, иначе кончатся бесплатные часы.
- Видео в базе занимают место, лимит 350 МБ на все файлы. Длинные уроки лучше на YouTube.
- Встроенный браузер иногда ненадолго теряет связь. Подожди 30-60 секунд и повтори.
