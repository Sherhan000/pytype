# pytype

Тренажёр скоростной печати кода на Python: задания по лигам, кубки, монеты и магазин, рейтинг, общий чат с защитой, ИИ-наставник на Groq и админка.

## Что внутри

- **Регистрация и вход.** Пароли хранятся в виде bcrypt-хеша, сессия в httpOnly-куке на 30 дней. Первый зарегистрированный пользователь сразу становится админом.
- **Задания и лиги.** Бронза, Серебро, Золото, Платина, Алмаз, Легенда. Пройдёшь все задания лиги, получишь кубок и монеты, откроется следующая лига. За каждое задание до 3 звёзд.
- **Защита результатов.** Время засекает сервер, а не браузер. Слишком быстрые результаты не засчитываются. Неполный набор кода тоже не засчитывается. В заданиях отключена вставка.
- **Монеты.** Даются за задания, новые звёзды, кубки, ежедневный вход (серия дней увеличивает бонус) и немного за свободную тренировку (не больше 60 в день).
- **Магазин.** Аватары, анимированные рамки, титулы, темы редактора и цветные ники.
- **Рейтинг.** По опыту, по скорости, по кубкам и за неделю.
- **Общий чат** в реальном времени. Фильтр мата, запрет ссылок, медленный режим, лимит сообщений, защита от повторов, мут и бан. Сообщение, которое начинается с `/ai`, получает ответ ИИ прямо в чате. Все права настраиваются в админке.
- **ИИ-наставник (Groq).** Отдельный чат с ИИ, разбор кода после задания, советы по твоим слабым символам. В админке ИИ сам придумывает новые задания. Есть дневной лимит вопросов.
- **Админка.** Статистика, задания, лиги, товары магазина, пользователи (роли, монеты, мут, бан, сброс прогресса), настройки чата и ИИ. Модераторы видят только пользователей и чат.
- Код можно запустить прямо в браузере (Python через Pyodide).

## Запуск у себя на компьютере

Нужен Node.js 20 или новее (nodejs.org).

```
npm install
npm start
```

Открой http://localhost:3000. Без настроек сайт работает на встроенной базе в папке `data/`. Чтобы локально работал ИИ, запусти так:

```
GROQ_API_KEY=твой_ключ npm start
```

На Windows в PowerShell: `$env:GROQ_API_KEY="твой_ключ"; npm start`

## Бесплатный хостинг: Render + Neon

Сайт крутится на Render (бесплатный тариф), база живёт на Neon (бесплатный Postgres, не удаляется через месяц). Карта не нужна. Всё делается мышкой, примерно 15 минут.

### 1. Залей проект на GitHub

1. Зарегистрируйся на github.com.
2. Нажми **New repository**, назови `pytype`, создай.
3. На странице репозитория нажми **uploading an existing file** и перетащи в окно **содержимое** этой папки (папки `server`, `public` и файлы `package.json`, `package-lock.json`, `render.yaml` и остальные). Папки `node_modules` и `data` не нужны.
4. Нажми **Commit changes**.

### 2. Создай базу на Neon

1. Зайди на neon.com, войди через GitHub.
2. Создай проект (регион ближе к тебе, например Frankfurt).
3. На главной проекта нажми **Connect** и скопируй строку подключения. Она начинается с `postgresql://`.

### 3. Возьми ключ Groq

1. Зайди на console.groq.com, войди.
2. **API Keys** → **Create API Key**, скопируй ключ (начинается с `gsk_`).

### 4. Запусти на Render

1. Зайди на render.com, войди через GitHub.
2. **New** → **Blueprint**, выбери репозиторий `pytype`. Render сам прочитает `render.yaml`.
3. Он попросит заполнить переменные:
   - `DATABASE_URL`: строка из Neon
   - `GROQ_API_KEY`: ключ из Groq
   - `ADMIN`: твой будущий ник на сайте (этот ник всегда будет админом)
4. Нажми **Apply** и подожди пару минут.

Готово. Сайт будет по адресу вида `https://pytype-xxxx.onrender.com`. Зарегистрируйся с ником из `ADMIN`, и у тебя появится вкладка «Админка».

Если **Blueprint** почему-то не подошёл: **New** → **Web Service**, выбери репозиторий, Build Command `npm install`, Start Command `npm start`, Instance Type **Free**, и добавь те же переменные плюс `NODE_ENV=production` во вкладке **Environment**.

### Как обновлять сайт

Меняешь файлы на GitHub (или загружаешь новые поверх старых), и Render сам пересобирает сайт через минуту-две. База и прогресс игроков при этом не теряются.

### Что важно знать про бесплатный Render

- Если на сайт никто не заходит 15 минут, он засыпает. Первый заход после сна грузится около минуты, дальше всё быстро.
- Чтобы сайт не засыпал, можно бесплатно настроить uptimerobot.com: монитор типа HTTP на адрес `https://твой-сайт.onrender.com/healthz` с интервалом 5 минут.
- Бесплатных часов хватает на один сайт, который работает круглосуточно.

## Как расширять

- **Новый серверный функционал.** Положи файл в `server/plugins/`, например `server/plugins/quests.js`:

  ```js
  export default function ({ app, need, adm, db, io, cfg, ask }) {
    app.get('/api/quests', need, async (req, res) => {
      res.json({ rows: await db.q('select * from tasks limit 5') })
    })
  }
  ```

  Плагины подключаются сами при старте. Файлы, имя которых начинается с `_`, пропускаются (там лежит пример).
- **Новая страница на сайте.** В `public/js/ext.js`:

  ```js
  App.nav.splice(7, 0, { r: 'quests', t: 'Квесты', i: 'flag' })
  App.page('quests', { title: 'Квесты', async render(v) { v.innerHTML = '<div class="card">Скоро</div>' } })
  ```

- **Новый тип задания.** У задания есть поле `kind` и свободное поле `meta` (JSON). Создай в админке задание с `kind = quiz` и зарегистрируй отрисовку: `App.kind('quiz', { render(el, task) { ... } })`.
- Все стили в `public/css/app.css`, цвета задаются переменными в начале файла.

## Структура

```
server/
  index.js     маршруты API, вход, задания, награды, магазин, рейтинг, ИИ
  chat.js      общий чат на socket.io и его защита
  admin.js     API админки
  ai.js        запросы к Groq и лимиты
  db.js        Postgres (Neon) или встроенная база для локального запуска
  seed.js      стартовые лиги, задания и товары
  util.js      настройки сайта и мелкие помощники
  plugins/     твои расширения
public/
  index.html
  css/app.css
  js/core.js     каркас: API, роутер, меню, вход
  js/trainer.js  редактор-тренажёр
  js/pages.js    страницы сайта
  js/admin.js    админка
  js/ext.js      место для твоих доработок
```
